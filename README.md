# すべての歯が見える

祭祀技師「すべての歯が見える」の相談・制作・観測記録サイト。

## 現在の構成

- トップページ: 口腔観測所
- 主導線: ココナラの霊視・電話占い
- 記録: 公開Googleスプレッドシートを読み込み、通信できない場合は予備記録を表示
- 未移設の各コンテンツ: `placeholder.html` で仮案内

## 公開前の確認

1. `index.html` をブラウザで開く
2. 375px / 768px / 1440pxで表示確認
3. ココナラ、X、noteへの外部リンクを確認
4. 公開URL確定後、canonical URLとOGP URLを絶対URLへ更新

記録の書き込み用認証情報は公開コードへ置かない。
