# すべての歯が見える｜ポートフォリオ・収益導線

祭祀技師「すべ歯」の公開サイト用リポジトリです。

## 現在の目的

最初に売るものを一つへ絞り、スマートフォンで見やすい一枚の販売ページを作る。

### 主サービス

- 霊視相談
- 通話20〜30分を想定
- 怖がらせず、状況と次の一手を整理する
- 医療・法律・投資・生死の断定をしない

### 次の商品候補

- 作戦会議
- 個別儀式設計
- 祭祀具制作
- PDF商品

## ファイル

- `index.html`：販売ページ本体
- `style.css`：画面デザイン

## 公開前に必要なもの

- ココナラ出品ページ、または予約・決済先URL
- プロフィール画像または代表作品画像
- 受付状況と料金
- 連絡先と規約表記
