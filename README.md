# すべての歯が見える｜霊能者の私室

霊能者「すべての歯が見える」の公開サイト用リポジトリです。

## 目的

- 霊視・電話占い・個別鑑定への導線を明確にする
- 映像、妹字、式神、絵などの活動を一か所に蓄積する
- 新作や動画を公開したとき、すぐ告知先として使える本拠地にする
- 信頼できる仕事と、奇人としての人物像を同時に伝える

## サイトの考え方

架空の商店街やゲーム世界ではなく、本人が深夜に相談、制作、調査、映像編集を続けている「私室」を公開する。

表側は信用、奥側は狂気。
取引条件は明快にし、世界観は部屋の物、記録、制作物の蓄積によって見せる。

## 現在の受付内容

- 霊視・電話占い：1分 180円
- 霊視鑑定（本気）：15,000円
- 制作依頼：妹字、オーダー式神、絵、その他の祭祀物

## 最初の映像記録

「式神の作り方｜何を入れれば、それは生き物になるのか」

撮影済み。公開後、サイトの小さいテレビ部分へ本編を接続する。

## ファイル

- `index.html`：ページ本体
- `style.css`：画面デザイン、部屋と物品のCSS表現

## 次に必要なもの

- 霊視鑑定（本気）の正式な受付URL
- 式神動画の公開URLとサムネイル
- VTuber画像または代表ビジュアル
- 匿名化した相談事例
- 妹字、式神、絵の作品画像
- SNSリンク
