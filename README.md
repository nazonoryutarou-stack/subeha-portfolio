## 実装

- 各入口の `index.html` は共通シェル
- ページ本文とCSSは `assets/chunks/` の圧縮データへ収録
- `assets/bootstrap.js` がURLに応じて各ページを展開
- 基本画面は外部画像、外部フォント、外部JavaScriptなし
- 制作者ページの3D表示時のみ Three.js と three-vrm を遅延読込
- スマートフォン対応、`prefers-reduced-motion` 対応
- 会員ページはUIのみ。認証・データベース・メール送信は未実装
- 顧客情報はGitHubや静的HTMLへ保存しない

## VRMモデルの配置

制作者ページは、次のいずれかの形式でモデルを読み込む。

1. `assets/vrm/subeha-web.vrm` を直接配置する
2. gzip圧縮したVRMをBase64化し、`assets/vrm/lite-00.b64` から `lite-26.b64` まで27片に分割して配置する

分割形式では、全27片が揃った場合だけ表示ボタンが有効になる。閲覧者がボタンを押した時点で各片を結合し、ブラウザ内でgzip展開してVRMを復元する。欠片が不足している間は、配置済み数を表示し、静止画版を維持する。

2026年8月5日時点では `lite-00.b64` の1片のみ配置済み。残る `lite-01.b64` から `lite-26.b64` の追加が必要。
