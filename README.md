# すべての歯が見える｜不氣屋界隈

蛭子【テッシ】の研究・観測と、心ばかりの心強さを扱う静的サイト。

## 基本文

> 呪われてても心は錦
>
> 2019年11月11日創業。
>
> すべての歯が見えるは、蛭子【テッシ】を含む霊的現象・祭祀技術・宇宙理論の研究や実践を行う、個人もしくは小規模の集団です。
>
> 不氣屋界隈では、霊的な問題にお困りの方へ、心ばかりの心強さを販売しております。

蛭子【テッシ】は、すべての歯が見えるの宇宙理論における最弱の量子。重力より弱い。

## 製品・活動の区分

1. 妹字
2. 式神
3. 術式・鑑定
4. 祭祀具・異物製品
5. 研究・作品

黒いてるてる坊主は「祭祀具・異物製品」に含まれる一製品として扱う。

## 主な入口

- `/`：不氣屋界隈トップ
- `/products/`：製品情報
- `/brands/imoji/`：妹字くんシリーズ
- `/brands/shikigami/`：しきがみ上手
- `/brands/jutsushiki/`：術式・鑑定
- `/brands/kuro-teruteru/`：祭祀具・異物製品
- `/quality/`：霊務品質
- `/research/`：蛭子・宇宙理論研究
- `/creator/`：制作者
- `/news/`：新着情報
- `/members/`：霊務記録閲覧室のUI試作
- `/private-room/`：制作者の私室
- `/works/`：特設ページ保管庫

## 実装

- 各入口の `index.html` は共通シェル
- ページ本文とCSSは `assets/chunks/` の圧縮データへ収録
- `assets/bootstrap.js` がURLに応じて各ページを展開
- 外部画像、外部フォント、外部JavaScriptなし
- スマートフォン対応、`prefers-reduced-motion` 対応
- 会員ページはUIのみ。認証・データベース・メール送信は未実装
- 顧客情報はGitHubや静的HTMLへ保存しない

## 公開運用

`main` ブランチへの更新をGitHub Pagesへ自動反映する。大幅改修前の状態はバックアップブランチへ保存する。
