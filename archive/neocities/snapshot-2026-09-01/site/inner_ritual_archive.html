異物標本室、
祭りの前夜。

ここは保管庫であり、準備場でもある。
排除されなかった異物が、分類され、注釈され、静かに点灯し、いつか踊り出すための空間。

孤独はここで標本箱に収まり、回復の代わりに変身の準備へ移される。人は見えない。だが、誰かがここで祭りを始めようとしている痕跡だけが、異様に整っている。

RECORD / 09-11 / 00:17

孤独は欠損ではなく、保管形式のひとつである。

ここでは、うまく説明できないものを未熟なまま保存してよい。分類保留は、失敗ではない。

注記：回復を目標としない。変化の前夜として保つこと。
ANNOTATION / CASE 03

祭りは騒音ではなく、密度の上昇として始まる。

音の代わりに配置が変わる。机の上の物が少しだけ前に出る。灯りが一つ増える。そこで準備は踊りに近づく。

参照：カセット、足跡、待機中のマイク。
CATALOG / FOLK FUTURE

未来の民俗資料室は、壊れかけの電子機器を捨てない。

古い本、御札、回路基板、封筒、録音メディア。時代が違っても、祈りは一度資料化される。

補足：アナログと発光体を、同じ棚に置く。
FIELD MEMO / SPECIMEN 07

怪物的であることは、知性を失うことではない。

異物はここで乱暴に消費されず、寸法を測られ、番号を与えられ、静かな照明のもとに展示される。

記録：深い赤の印、蛍光グリーンの残留、青い発光面。

Observation

“人物不在だが、人の気配だけが濃く残る” 状態を維持中。

Classification

標本、紙片、回路、祭具、録音媒体。カテゴリーは交差したまま保存。

Margin

密度の高いモジュールのあいだには、呼吸のための静かな余白を残す。

Warning

過度な説明を避けること。理解の前に空間として成立させること。

Traces / Before Activation

祭りの痕跡

人はまだ現れない。だが、足跡、椅子、カセット、マイク、半描の怪物、机の上の移動した紙が、すでに何かが始まることを知っている。

TRACE / ENTRY

足跡

導線だけが先に現れる。棚の前、記録机の脇、展示ケースの手前。祭りはまず、歩行の癖として現場に残る。

TRACE / VOICE

置かれたマイク

発声の準備。朗読か、祝詞か、報告かはまだ未定。沈黙の直後にだけ使われる道具。

TRACE / SOUND

光るカセット

再生待機。巻き戻された磁気テープの青い呼吸。

TRACE / ABSENCE

空の椅子

不在そのものが配置として残っている。座っていた気配だけが濃い。

TRACE / DRAFT

半分だけ描かれた怪物

完全体ではなく、変身の途中が保存される。輪郭線、補助線、塗り残し。脱皮の最中であること自体が主題になる。

Terminal / Quiet Exit

この異界は、
すでに成立している。

理解は遅れてやって来てもよい。ここでは異物が排除されず、分類され、保管され、ときどき静かに発光する。それだけで空間は十分に生きている。

収蔵庫はいつでも祭りへ変わりうる。誰かがその準備を続けている限り、内面は保管庫のまま終わらない。
