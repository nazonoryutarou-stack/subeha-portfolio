# 不氣屋アーケード 開発メモ

## 目的
狭い、汚い、古いアーケード商店街を、不氣屋界隈の歩ける常設空間として育てる。通販サイトの入口ではなく、作品・研究・商品が同じ街路に混在する場所にする。

## 確定した方向
- 道幅は狭い。向かいの店が近く、圧迫感がある。
- 天井は低い半透明アーケード。昼でも暗い。
- 壁、シャッター、看板、床は汚れ・錆・退色を強く出す。
- 不気味なネオンを少量配置。色は統一しすぎず、壊れかけ・瞬き・色温度差を残す。
- 配管、ケーブル、ダクト、メーター、ブラケットなどを大量に置く。機能が分からないものが混在してよい。
- ただし『全部が同じ店の箱』にはしない。店舗ごとに間口、階高、入口、シャッター、看板、二階、庇を変える。
- 実在商店街の雑多さを参照しつつ、固有の店として再設計する。
- 商品販売は後付け可能にするが、空間自体を作品として成立させる。

## 現在の試作
`/arcade/`

WIP 0.1では以下を実装済み。
- 狭い通路
- 低いアーケード屋根
- 左右の店舗列
- 汚れた外壁とシャッター
- 点滅する赤・青緑・紫ネオン
- 用途不明の縦横配管
- 天井を横切るサービスケーブル
- 店移動 / 左右列切替 / 視点回転 / ズーム
- 不氣屋界隈の仮店舗名と囁き

## 次回以降の優先候補
1. 店舗モデルの固有化。まず3店舗だけ完全専用モデルにする。
2. アーケード屋根を平板から、鉄骨・波板・破損パネル・雨樋の集合体へ変更。
3. 配管を壁面だけでなく、店から店へ無理に跨がせる。途中で塞がれている管も作る。
4. 室外機、換気扇、古い分電盤、電線、手書き注意書き、濡れ跡、剥離タイルを追加。
5. 看板を平面テクスチャだけでなく、箱文字・袖看板・電飾・手描き板・消えた屋号に分ける。
6. 『妹字屋』を最初の完成店舗にする。黒和紙、金文字、暗号台帳、読み札などを店内外に置く。
7. 商品ページへの遷移は、店の完成後に導入する。

## 禁止事項
- 全店を同一テンプレートの色違いにしない。
- ネオンをサイバーパンク風に整えすぎない。
- 配管を見栄えだけの均等配置にしない。
- 清潔な観光地・テーマパーク風にしない。
- 一度に全店舗を作り直さない。息抜きとして一店舗ずつ育てる。
