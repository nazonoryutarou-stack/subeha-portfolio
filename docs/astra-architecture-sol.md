# アストラ建築 — Sol版

## 定義

「アストラ建築」は特定の見た目のスタイル名ではない。AIに3D空間を作らせる際、**一箇所を完成品質まで作り、空間ルールを数値化し、自動QAと実操作を往復してから増築する制作プロトコル**を指す。

アストラ版の不氣屋アーケードから、完成物ではなく工程を継承する。

## Sol版の原則

1. **先に禁止事項を書く。** 「何を作るか」だけでなく、テンプレ化・過剰なネオン・整いすぎ・テーマパーク化など、失敗した時に出やすい見た目を先に禁止する。
2. **Vertical Sliceを一棟だけ作る。** 最初から街や施設群を量産しない。一棟の入口、内部、対象物、出口まで成立させる。
3. **用途ごとに建築を変える。** 色だけで用途を表現しない。天井高、間口、家具密度、開口、光源、材質、導線を変える。
4. **情報を創作で補わない。** 既存ページへ接続する場合、そのページに存在しない設定・効能・歴史を空間側で勝手に追加しない。
5. **見た目と物理を別々に検査する。** 「扉が閉じて見える」と「プレイヤーが通れない」は別問題。衝突判定を自動検査する。
6. **狭さも意図として数値化する。** 到達面積の大きさだけを品質にしない。狭い空間では対象物への接近可能距離を別に検査する。
7. **未検証を完成と呼ばない。** WebGL実描画、スマートフォン同時タッチ、実機FPSなど未確認の項目は、そのまま未確認と記録する。

## 001：祭祀技師事務所

最初のVertical Slice。アーケードの商店を再利用せず、「表に立つ人間の後ろで、道具・記録・書類が増えていく裏方の事務所」を建築テーマにした。

### 空間

- 入口：低天井。正面から奥まで見通せない。
- 受付：高い木製カウンター、紙の台帳、古い金属柵。
- 書類机：比較的整った机だが、ケーブルと紙束が侵食している。
- 祭祀作業場：棚、工具、配管、作業台が密集。入口より天井が少し高い。
- 検品室：冷たい照明、金属机。点滅停止設定を持つ。
- 保管庫：一人が入って目録を見る程度の狭さ。広い展示室にはしない。
- 閉鎖室：格子の手前までは入れるが内部は衝突判定でも侵入不可。

## QA

`npm run astra:check`

検査内容：

- HTML/CSS/JSの必要ファイル
- JavaScript構文
- ローカル参照・接続先の実在
- スタート地点の衝突
- 0.18mグリッドでの到達可能領域
- 受付、書類机、作業場、検品室、保管庫、閉鎖室前、奥廊下への到達
- 主要な操作対象へ近づける地点の存在
- 閉鎖室内部の到達点が0であること

### 現時点で未検証

- WebGL2実描画の美術品質
- 透過・フォグ・ACESトーンマッピングの実画面
- iPhone / Androidの二指同時操作
- 実機FPS、発熱、DPR自動調整
- 実際に見た時の暗さ、文字の可読性、対象物の発見しやすさ

これらを確認するまでは、001を「完成版」とは呼ばない。
