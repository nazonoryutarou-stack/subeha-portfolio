# Catalog candidate inventory

Neocities の `public/data/general.json` / `public/data/trade.json` を実データへ置き換える前の、現行リポジトリ内ソース確認用メモ。

## 原則

- 商品名・状態・説明は、本人が実際に出した案または現行リポジトリに明示された内容だけを使う。
- AIが効能、由来、世界観、販売対象を補完しない。
- `一般` / `同業者` の振り分けは、明示的な根拠があるまで確定しない。
- 古い公開原稿より `IDEA_NOTE.md` の現行制約を優先する。
- `妹字` は現行商品候補から一旦説明削除済み。本人が文章を指定するまで公開説明を追加しない。

## 現行ソースで確認できる候補

| 名称 | 現行状態 | 公開データ化 | 備考 |
| --- | --- | --- | --- |
| テルテルボット | 商品化進行中 / 受注生産 | 候補 | 実物10体完成後、仮画像を実物写真GIFへ差し替える予定 |
| モールスポマンダー | アイデア | 保留 | 商品仕様・販売対象は未確定 |
| 見境なき石弾 | アイデア | 保留 | 販売時は名称・寄付表記・団体名の扱いを事前確認 |
| カウベル由来の魔除け | 素材あり / 未設計 | 保留 | 名称・加工方法・用途が未確定 |
| 鬼斬り | 既存アイデア | 候補 | 大豆由来素材を使った日本刀型の祓具 |
| 化石護符 | 既存アイデア / 優先素材 | 候補 | 具体仕様は制作時に確定 |
| ナーバ流し | 制作経験あり / 完全版制作済み | 候補 | 実物が残っていれば撮影して再利用可能 |
| 無器官昆虫 | 既存アイデア | 候補 | 3Dプリント等の制作候補あり |
| 妹字 | 既存システム / 現行商品候補から説明削除済み | 説明追加禁止 | 本人指定まで公開説明を補完しない |
| 式神関連の物体・筐体 | 既存実践 | 候補 | 具体的な効能・仕様は本人明示分だけ扱う |
| 時報經 | 既存プロジェクト | 保留 | 商品仕様未確定 |
| 手捏ねの祭祀物 | 制作方針 | 保留 | 単独商品名ではなく制作方針 |

## 既存公開データの状態

`public/data/general.json` と `public/data/trade.json` は現在、ツリーUI検証用の `仮商品種` / `仮商品` データで構成されている。

次の置換では、まず `一般` / `同業者` の明示的な振り分け根拠を確認し、確定したものだけを公開JSONへ移す。未確定候補を埋め草として混ぜない。
