# 配信・作品の入口整備（2026-10-02）

## 公開対象
既存の正本 `nazonoryutarou-stack/subeha-portfolio` の `public/` を更新する。公開先は引き続きNeocitiesと既存GitHub Pages。別サイトを作らない。

## 変更
- トップを、作品・語録・配信・商品・ごあいさつの順にする。
- 完成済みの「忍者解釈」を `public/works/ninja-kaishaku/` に収録する。著者の本文は原稿からそのまま複製し、入口だけを公開先に依存しない相対リンクにする。
- 本人が提示した語録の12片を `public/words/` に収録する。本文はHTMLに直接入れ、JavaScriptがなくても読めるようにする。正本データは同ディレクトリの `data.json`。
- 古文書文庫と理論を読む入口を作る。古文書本文・索引・未完成アーケードは変更しない。
- GRAVITYの媒体名と、確認できた本人の表示名「すべての歯が見える」を掲載する。プロフィール共有URL・IDは未確認なので、リンクや配信埋め込みを推測で作らない。配信中表示や日時も作らない。
- 現行公開トップのごあいさつ、および `home.html` の丁子方のごあいさつを文面を変えずに読める形で残す。
- 商品価格と既存のStripe購入先を維持する。
- トップ・商品・理論の本文とナビゲーションをスマホで読みやすくする。公開するページの `noindex,nofollow` を解除する。
- 会員課金・成人向け導線・新しい動画・新たな外部プロフィールURLは追加しない。

## 手動反映
GitHub Actionsを使わず、同じ内容のNeocities用更新ZIPを作る。ZIP内の更新ファイルだけを既存サイトへ上書きし、他のファイルを削除しない。
`hitotsu-ore-choji.png` は正本の既存画像をそのまま含める。
変更のコミットには `[skip ci]` を付け、Actionsの実行を前提にしない。

## 続き
GRAVITYアプリの本人プロフィールから取得した共有URLを、トップの配信案内へ設定する。本人のリンクが確認できるまでは名前による案内を維持する。
