IMOJI CRYPTOGRAPHY / EXPERIMENT 0.5

妹字暗号ラボ

装飾ゼロ。見えている形状差はすべて暗号情報。呪文と読みを指定すると、各線の長さ・曲がり方・曲がる向き・点の有無、さらに中央骨格の形まで暗号から決まる。

生成

同じ呪文＋同じ読みなら、毎回まったく同じ字形になる。

1. 呪文を数字にする
-
2. 0と1にする
-
3. 読みから鍵を作る
-
4. XORで混ぜて暗号にする
-
5. 暗号を字形の部品へ割り当てる
-

形の意味

bit1
0=短い / 1=長い
bit2
0=直線 / 1=湾曲
bit3
0=左へ曲がる / 1=右へ曲がる
bit4
0=点なし / 1=点あり

直線のときもbit3は無駄にしない。直線の「傾く向き」として読む。つまり4bit全部が常に意味を持つ。
