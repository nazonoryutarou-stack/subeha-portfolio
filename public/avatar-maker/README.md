# AVATAR ATELIER — スマホ向け3Dキャラクター制作アプリ

公開予定URL: https://nazonoryutarou-stack.github.io/subeha-portfolio/avatar-maker/

VRoid Studioの「顔・髪型・体型・衣装を直感的に編集する」制作フローを参考に、独立した3Dアバター制作アプリを実装した**試作版**。VRoid Studioのアセット・モデル・ソースコードは使用していない。

## 現在できること

- スマートフォンのWebGLで、独自のアニメ調3Dキャラクターを最初から生成（他のVRMファイルを必要としない）。
- 顔：頭部・輪郭・瞳・眉・口角・耳・鼻の調整と、目の形の選択。
- 髪：ショート、ボブ、ロング、ポニーテール、ツインテール。分け目・前髪・毛量・長さ・ウェーブ。
- **正面から指で髪の毛を描き足す**：モデルにタッチすると3Dストランドを頭のボーンに追加。最大36本・72点/本。設定JSONに保存され、3D書き出しの対象となる。現時点では正面描画のみ。
- 体型：身長、肩幅、胴、腰、脚・腕の長さ。
- 衣装：シャツ、パーカー、ジャケット、ワンピース、スカート・パンツ・ショートパンツ。袖・襟・裾の調整。
- アクセサリー：眼鏡、猫耳、ヘッドホン。
- 肌・髪・瞳・服・靴・装飾の色変更、5つの外観プリセット、ランダム生成。
- リグ：15のVRM必須ボーンを含むヒューマノイド階層を生成。SkinnedMeshを使用した身体部位と、頭に追従する顔/髪を備える。
- 顔の表情モーフ：まばたき・笑顔・悲しみ・怒り・驚きと、あ/い/う/え/お。
- プレビュー：指でモデルの角度変更・ピンチ拡大、表情・簡易動作テスト、PNG静止画。
- Undo/Redo、端末内自動保存、設定JSONの書き出し・読み込み。
- **GLB出力**：Three.jsのGLTFExporterでジオメトリ、素材、スキニング、モーフをGLB化。
- **VRM1.0出力（実験的）**：GLBに `VRMC_vrm` エクステンション（Humanoid/Meta/Expressions）を付加。必要な15ボーン参照とモーフ参照を検査し、three-vrmで再読み込みできた場合だけダウンロードを許可。再読み込みエラーなら理由を表示。

## VRM STAGEとの併用

1. AVATAR ATELIERでアバターを作る。
2. 「モデル書き出し」→「VRM 1.0 保存」を選択。
3. [VRM STAGE](../vrm-stage/) の「VRMを選択」で保存したファイルを読み込む。
4. 音声を読み込み、カット別の表情・身振り・カメラを設定し動画化。

**VRM STAGEに自動送信する機能はまだない**。VRMが正常に書き出せなかった場合、GLBで中間出力し、ボーン対応などを確認する必要がある。

## 重要な限界

本家VRoid Studioの完全再現ではない。現行モデルは**手続き的に生成する単純化したアニメ風メッシュ**であり、本家の精密な顔・髪・体型の造形品質、自由な衣装裁断、UV/テクスチャペイント、物理演算付きの髪、XWear、VRoidファイル形式の読込・編集、ボーンウェイトのペイントは未実装。

本アプリのVRM書き出しはコード上で構成・検証を実装したが、**実際のAndroid端末でのWebGL表示・GLB/VRM保存・VRM STAGEへの読み込みをまだ確認していない**。デバイスやブラウザのWebGL・メモリ・GPU制約により動作や書き出しが失敗する場合がある。UI内の失敗表示は安全側に倒している。

## 動作条件と権利

- HTTPS/ChromeなどWebGL 2.0が利用できるブラウザ。Three.jsとthree-vrmはCDNから読み込むため初回はオンライン必須。
- 作者名・利用規約はエクスポート時に明示的に指定可能。商用利用・政治/宗教的用途・再配布・クレジット条件を自分で選択できる。
- VRM1.0仕様：[VRM Consortium](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/README.md)。
- Three.js [GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html)。
- VRoid Studioのモデルや本体を取り込んで改造したものではない。

## テスト

- `node --test public/avatar-maker/test/*.test.mjs` でパラメータの正規化・設定保存・髪ストローク・GLB/VRMチャンク構造等の単体テスト。
- JavaScriptの静的構文検査とテストデータのGLB/VRMラウンドトリップは確認できる。
- **GPU実装とVRM/GLBの実ファイル生成の端末実走は未検証**。確認前に「完全動作」とは呼ばない。
