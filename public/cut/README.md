# SUBEHA CUT v2.0 — 先進機能ラボ（42機能を登録、5つの解析・操作ワークフローを追加）

Android Chrome/PWA向け。既存の動画・字幕・オーバーレイ・無料素材ライブラリ・3D CGは保持し、Deep Researchで検討した高度編集機能の入口を統合。

## 今回追加した実処理

- **ビート候補検出**：Web Audioでデコードできる音声（BGM/選択クリップ/音声トラック）をRMS変化から解析し、候補の時刻へジャンプ／マーカー保存／確認後に最大48カ所を分割。音楽の拍を完全に推定するものではありません。
- **無音区間検出**：デコード可能な音声のRMSから無音開始・終了を候補として表示。強さ閾値を変更可能。
- **シーン切替候補**：選択した動画の先頭最大48秒を低解像度サンプリング。画素差が大きい位置を候補化。カメラの激しい移動で誤検出する場合があります。
- **文字起こしナビ**：SRT/VTT/Whisper JSONを読み込み、文字列検索→タイムコードへジャンプ。明示的な確認後に既存字幕トラックへ配置。音声の自動文字起こしや発話単位での自動カットは未実装。
- **日本語コマンド**：分割、速度変更、比率変更、再生位置移動、文字追加、ミュートの限定文型を解釈。自由文の生成AIではありません。
- **42機能の一覧**：機能の説明・想定処理・利用可否を区別。未接続のAI機能を実行済みと表示しません。JSON一覧を保存できます。

## アクセス方法

編集画面の下の横スクロールツールバー「先進機能」から開く。または「すべて」→「先進機能ラボ」。
既存クリップやBGMなどを読み込み、ビート・無音・シーン解析を選択。結果の時刻をタップして確認し、必要な候補だけをマーカー保存または一括分割してください。

## 現時点の制約

- 登録した42機能すべての実行エンジンが完成したわけではありません。ロトスコープ・映像生成・本格3D再構築などはモデルやAPI／Androidネイティブ実装が未接続です。
- 音声の `decodeAudioData` は形式依存。特に一部の動画ファイルは直接解析できないため、音声ファイルで試してください。ファイルのデコードは最大70MBまで、解析時間は原則120秒までです。
- 検出は軽量な推定であり、プロ品質のビートトラッキング・音声認識・シーン認識ではありません。長尺素材では発熱と処理負荷に注意。
- AI APIキーを勝手に取得・課金したり、動画をサーバーへ送信したりしません。
- 端末実機の長尺動作・公開サイトへの反映は別途検証が必要です。既存の自動テストに追加した `test/feature-lab.test.mjs` はNode実行で検証可能です。

# SUBEHA CUT v1.9 — 権利情報付き無料素材ライブラリ

Android Chrome対応のローカル動画編集PWA。独自開発でありVideoleap等の他社製品とは無関係。

## この版で追加したもの

- アプリの下の「無料素材」から、**画像・動画・音声の検索、素材の直接取り込み、端末保存**が可能。
- **Openverse**: 画像と音声。認証キー不要の公開APIから **CC0** の素材のみ表示。検索 API は回数制限あり。Openverse掲載の著作権表記はデータソースの宣言であり、完全性は保証されません。
- **Wikimedia Commons**: 画像・動画・音声。素材の著作権表示を検索結果から取得し、CC0またはパブリックドメイン系だけを表示。ファイルごとの使用条件・元画像を確認できます。
- **Pixabay / Pexels**: 公式検索ページへのリンクと「端末から追加」。APIを用いた直接検索・取り込みは未実装。キー管理や各社API利用条件の同意なくスクレイピングしません。
- 検索結果に**作者、原典、許諾情報、個別のライセンスリンク**を表示。
- 編集へ読み込んだ素材の権利情報をプロジェクト内 `stockCredits` に保持。`.subecut`へ含まれ、権利情報のテキスト書き出しも可能。
- 他社配信サーバーからダウンロードした素材は**端末のブラウザに保存**。完成動画や個人の元動画を外部サイトへアップロードしません。素材検索の検索語は外部サービスへ送られます。
- サイズ上限は一つの素材につき80MB。ブラウザが相手先のCORS制御でダウンロードを拒否した場合は、素材ページを開いて手動保存→「端末から追加」。
- v1.8までの文字・字幕・重ねがけフィルター・3D CG・音声・映像書き出しを保持。

## 宗教団体の広告・広報での利用条件（重要）

**「無料」や「CC0」であっても、その画像が宗教団体の宣伝に必ず使えると保証できるわけではありません。** 著作権とは別に、写る人物の肖像権・プライバシー・商標・撮影されている美術作品・建築物などの権利があり得ます。信者・勧誘スタッフ・公式支持者に見えるような表現には当事者の承諾が必要になることがあります。政治的用途等への制約はサービス・作品により異なります。

**Pixabay**（https://pixabay.com/service/terms/ ）は商用・非商用の編集利用を許容しますが、素材単体の再配布、誤認を生む推奨表現、人物の不適切な使い方を禁止しています。**Pexels**（https://www.pexels.com/legal-pages/license/ ）も広告利用を認めつつ、人物やブランドによる推奨を示唆する使い方などを禁じます。事前に素材ごとに確認してください。

**Wikimedia Commons**（https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia）と **Openverse**（https://docs.openverse.org/ ）は素材ごとの利用条件が異なるため、アプリで出典・ライセンスを確認できるようにしました。OpenverseはCC0の検索フィルターを利用します。

## 使い方

1. アプリ下部から**「無料素材」** → 検索語（英語推奨）→ **「画像」「動画」「音声」**を選択。
2. 出典ページ・ライセンス・人物や商標等を確認して、チェックを入れる。
3. **「編集に追加」**を押すと、元からある素材追加機能へ渡して時間軸に取り込む。**「端末へ保存」**で別途ファイルを保存できる。
4. **「使用素材の記録」**から出典を確認できる。必要なときに権利情報のテキストを保存する。
5. 外部リンクのPixabay / Pexels素材はサイト側でダウンロード後、「端末から追加」で取り込む。

## 検証

```
cd public/cut
for f in *.mjs integrations/*.mjs; do node --check "$f" || exit 1; done
node --test test/*.test.mjs
python test/smoke-stock.py
```

Node 51件の自動テスト成功。Chromiumのモバイル画面で**モックAPIからCC0画像取得 → 既存のクリップ読み込み → 出典記録**まで検証済み。**外部公開APIのライブ接続はこの実行環境で検証不能**（外部へのDNS通信不可）。公開環境での検索・ダウンロードについては、通信環境、提供元の仕様変更やCORS制限により結果が変わり得ます。Android Nothing Phoneの実機テストも未実施。
