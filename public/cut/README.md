# SUBEHA CUT v1.7 — 編集データの安全な保存と書き出し中止

Videoleapなどのスマホ編集アプリで一般的な操作を参考にした、独立開発のAndroid Chrome向け動画編集PWAです。Lightricks/Videoleapとは無関係であり、他社の専用コード・ロゴ・素材を複製していません。

## 今回の中心: 指でつかんで削除

- **動画・写真、文字、字幕、3D映像**：時間軸で対象を約0.42秒長押しすると、ゴミ箱が表示されます。そのまま指をゴミ箱の上に運んで離すと削除できます。
- **音声、重ねた画像・動画**：時間軸上の素材をドラッグするとゴミ箱が表示されます。ゴミ箱へ持ち込めば削除、それ以外の位置で指を離せば開始時間の移動になります。
- **プレビュー上の文字・字幕・重ねた素材**：今まで通りドラッグで位置を変更できます。画面下側にドラッグして、表示されたゴミ箱で離すと削除できます。
- **誤操作対策**：ゴミ箱の外で指を離しても削除されません。削除直後に「元に戻す」ボタンを表示します。元の素材データは破棄しないため、編集履歴から復元できます。
- **Androidタッチ対策**：長押し中は不要な選択メニューを抑え、ドラッグ中のスクロール処理が操作を中断しないよう修正。従来のタイムラインの左右スクロールと2本指での拡大縮小を保持。
- **詳細設定パネルを邪魔にしない**：画像レイヤーや音声の取り込みが終わったら編集パネルを閉じ、時間軸へ戻ります。

## 日本語表示・操作ガイド

- 画面の「？」を押すと**操作の説明と用語集**が開きます。
- 「オーバーレイ」→「素材を重ねる」、「クロマキー」→「背景色を消す」、「トランジション」→「場面のつなぎ」、「エフェクト」→「映像効果」、「キーフレーム」→「動きの記録点」など、専門語をわかりやすい表示に変更。
- レイヤー位置の `x/y`、`scale`、`opacity`、`rotation` は「左右の位置」「上下の位置」「大きさ」「透明度」「回転角度」へ変更。重なり方の選択肢も日本語に変更。内部データの値や既存プロジェクトは変更しません。
- 数値欄は微調整用で、普段は画面で素材を直接動かしたり拡大・縮小したりできます。

## 主な従来機能

動画・画像・音声の複数トラック、トリム、分割、並べ替え、場面のつなぎ、色の調整・映像効果、文字・字幕（SRT/VTT/Whisper JSON）、背景色を消す、時間ごとの動き、OBJモデルからの3D映像制作、素材入り `.subecut` バックアップ、動画書き出し。

## 限界

- Nothing Phoneの実機でのタッチ操作、長尺編集・発熱・書き出しは未検証。テストはChromiumのモバイルエミュレーションです。
- ブラウザのMediaRecorderが出力するMP4コンテナは、H.264/AAC形式とは限りません。確実な4K・長尺・HEVC書き出しは保証されません。
- 削除はプロジェクト上の参照を取り除く操作で、ストレージ上の元ファイルを永久消去する操作ではありません。復元に必要なデータは保持します。
- 一部の映像用語は従来のプロジェクトとの互換性のため内部の変数名に残っていますが、画面の操作名称・説明を優先して日本語化しています。

## v1.6 — 色フィルターを本当に重ねがけできる編集

- 「色フィルター」から **12種類** の色補正を、同じ動画／写真クリップに **最大16個** 重ねて適用。明るさ、コントラスト、彩度、白黒、古い写真、暖色、寒色、ぼかし、色反転、色ずれ等。
- **各効果は独立**: 強さ0〜100%、表示／非表示、↑↓・ドラッグによる適用順変更、個別削除。押している間だけ加工前を表示する「比較」も追加。
- **ほかの全クリップへコピー**: 現在のクリップの色フィルターとその強さ／順番を一括適用。複製時にも編集情報を複製。元に戻す／やり直す、IndexedDBの自動保存、`.subecut`の素材入りプロジェクト復元で保持。
- 既存の単一フィルター、色調整、重ねた映像効果（FXレイヤー）とも併用可能。プレビューと動画書き出しは共通のCanvas2Dフィルター描画を使用するため、設定が書き出しにも反映される。
- フィルター一覧は元の画像の小さなプレビューを表示。処理はすべて端末内。データの意味が分かるよう全項目を日本語で表示。

## v1.7 — 失敗しにくい編集・保存・書き出し

今回の改修は新しい演出を増やすものではなく、編集結果を失わずに取り出せるようにする修正です。

- **「保存」の意味を修正**：上部の「保存」および最下部の「保存」から、動画・写真・音声・OBJを含む `.subecut` プロジェクトZIPを作ります。従来の編集情報JSONは「設定だけ保存（素材なし）」へ改称しました。素材入りバックアップには既存の**200MB上限**があります。
- **自動保存の起動競合を修正**：アプリの初期キャンバス設定がプロジェクト読込前に保存を予約し、復元データを上書きする可能性があったため、起動時の自動保存を停止。復元が完了してから保存処理を有効にします。
- **保存状態を表示**：保存中、自動保存成功、失敗を管理。自動保存が利用できない場合は、素材込みバックアップを案内します。Androidのブラウザがデータを消去する可能性は残ります。
- **書き出し中止**：動画記録中に「書き出しを中止する」を押すと収録と映像再生を停止し、**不完全な動画はダウンロードしません**。停止後、設定を変えて再度書き出せます。
- **書き出した動画の形式を検査**：`MediaRecorder`の指定MIMEだけではなく、実際のファイルヘッダーと一部のコーデック識別子を確認。実体がWebMなら拡張子をWebMに補正。MP4にVP9やOpusが入る等、再生互換性に問題があり得る場合は警告を表示します。**検査は軽量な署名確認で、H.264/AACへ変換する機能ではありません**。
- **従来のフィルター重ねがけ等を維持**：保存ZIPからフィルター設定が復元されることを確認しました。
- PWAキャッシュ名は `subeha-cut-app-v17` に更新。旧版キャッシュを更新するにはChromeでページを開き直します。
