# SUBEHA CUT v1.8 — 指先で自由に文字を編集

Android Chromeで動くローカル動画編集PWA（独立実装）。Videoleapとの関係はなく、専用コードや素材の複製ではありません。

## 今回の更新: 文字と字幕の自由度

- **指で選ぶ**：プレビュー上の通常のテキストと字幕をタップして選択。ドラッグで位置を移動し、画面中央に近づくと中心線に吸着。
- **指で拡大・回転**：2本指のピンチとひねり、選択枠右下「↘」でサイズ、上の「⟳」で回転。
- **枠の幅を直接変更**：選択枠の右端「↔」をドラッグして自動改行の幅を変更。改行位置は完成映像にも反映。
- **2回タップで編集**：文字の上を素早く2回タップすると文字入力画面が開く。
- **日本語の編集タブ**：「文字」「字体」「色と縁」「配置」「動き」。文字の色・縁取り色と太さ・影の位置とぼかし・背景色と濃さ・文字間隔・行間・文字の左右揃え・文字枠の幅を調整可能。
- **字体とデザイン**：標準・明朝・等幅・丸文字・手書き、映画風・ネオン・ニュース・シンプル・レトロ。字体は端末内のフォントへフォールバックするため機種依存。
- **字幕ごとの装飾**：読み込んだSRT/VTT/Whisper JSONのタイミングを維持しながら、セリフ単位で位置、文字サイズ、回転、幅、字体、文字間隔、影、背景を変更。通常の文字と字幕で同じ描画エンジンを使用。
- **映像への反映**：通常のプレビューと動画書き出しは同一Canvas描画経路。編集枠・ハンドルはDOMだけに描き、書き出しには写らない。
- **非破壊編集**：各要素のパラメータは従来のプロジェクトJSONに追加保存され、`.subecut`のバックアップに含められる。旧ファイルは既定値で描画。

## 基本操作

1. 映像または画像を取り込み、「テキスト」から「＋テキストを追加」。プレビュー上の文字に枠が現れる。
2. 文字をつかんでドラッグ。↔で折り返し幅、↘でサイズ、⟳で回転。2本指のピンチ・ひねりも可能。
3. 文字を2回タップするか、プレビューの「文字」を押して文章を編集。「字体」「色と縁」「配置」で好きな装飾にする。
4. 字幕は「字幕」からSRT/VTT/Whisper JSONを読み込み、再生位置の字幕をタップして同様に編集。
5. 完成したら上部「書き出す」。編集内容を再利用するには「保存」で素材を含む `.subecut` を保存。

v1.8では文字組み・操作・字幕共通描画・Undoの整合性を重視。Nodeテスト、Chromiumの幅420pxでタッチ編集・字幕個別装飾を確認。Nothing Phone実機での文字入力キーボード、多指操作、書き出し時間と端末負荷は未検証です。

既知の制限: 端末のフォント依存、RTL・縦書き・文字単位のモーションは未実装。多数の長文テロップではCanvas2D描画負荷が増加。書き出しは従来どおりブラウザのMediaRecorderに依存し、H.264/AACや4Kは保証しません。
