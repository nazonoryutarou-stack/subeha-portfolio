# SUBEHA CUT v2.1 — 台本字幕 / VRM口パク / 指で3D編集

Android Chromeで動作するローカル動画編集PWA。GitHub Pagesから利用可能。Videoleapと同一のソース・素材ではなく、独自実装です。

## v2.1追加

1. **音声から編集可能な字幕を生成**：合成音声の元になった日本語台本を句読点・文字数に基づいて分割。音声クリップの開始時刻と長さへ比例配分し、字幕トラックへ追加する。字幕の時刻は**推定**であり、ASR・音素アラインメントではない。既存の指で字幕を動かす・大きくする・色を変える機能が使える。音声作成画面で字幕を追加するかを選べる。
2. **VRM口パク（限定対応）**：VRM 1.0の表情 `aa`、VRM 0.xの `a` に対応するモーフターゲット形状を読み込み、合成された**PCM16/float32 WAV**の音量変化で口を開閉する。口の形状が埋め込まれていないVRMは動かない。顔を認識したり、正確な音素別口形状やボーン変形を計算する機能ではない。3D編集画面で既存のナレーション音声と手動でも連動できる。モデル素材の利用条件は引き続き確認する。
3. **3Dモデルの指操作**：「3Dを指で動かす」を有効にすると、プレビュー上のドラッグで左右・上下移動、2本指で拡大縮小・左右回転。通常の文字・レイヤー指操作を邪魔しないよう、専用操作中だけ有効にする。移動結果は編集履歴に保存。
4. **3D描画の更新**：GPUが使える場合にはWebGLの頂点シェーダーで口形状を合成。WebGLが使えない場合は従来のCanvas2D代替描画を使用。静的OBJ・口形状のないGLB/VRMは従来通り表示する。Service Workerキャッシュをv21に更新。
5. **既存の保存・編集互換**：以前の`.subecut`を読み込み可能。新しい字幕と音声・VRM間のリンク情報も素材込みアーカイブで保存できる。既存の動画・画像・字幕・重ねがけフィルターなどの編集機能を保持。

## 使い方

- 映像・写真を追加し、下の「3D映像」からVRMを読み込む。「3Dを指で動かす」を選び、モデルをドラッグやピンチで操作する。通常の文字編集に戻る場合は同じボタンで解除する。
- 「声を作る」でVOICEVOX互換エンジンへ接続し、音声を選択して台本からWAVを生成。「台本から字幕も自動作成」を有効にしたまま「音声を時間軸に追加」で字幕も作成。字幕の時間は必要に応じて修正する。
- VRMに `aa` の口形状があれば、音声追加時に連動させるか、3D映像の「口パクと連動する音声」から選ぶ。合成音声は非同期で追加されるため、再生前にWAVを保存・読み込む必要がある場合もある。
- 「保存」で動画素材・モデル・音声・字幕をまとめて`.subecut`へ保存。「書き出す」で完成映像を保存。

## 確認した動作

```sh
cd public/cut
for f in *.mjs integrations/*.mjs; do node --check "$f" || exit 1; done
node --test test/*.test.mjs
python test/smoke-v21.py
python test/smoke-v21-morph.py
```

- Nodeで既存62件＋追加7件＝**69件の自動テスト**。
- Chromium（モバイル420px）で、モックVOICEVOXエンジンのWAV生成→音声追加→字幕生成、CGを指で移動（実タッチ入力を含む）、素材入りアーカイブのZIP内容確認、720×1280程度の短い動画書き出しを検証。ページJavaScriptエラーなし。
- VRMの `aa` モーフを使い、Canvas2D代替レンダラーで口開閉前後のレンダリング画素が変化することを検証。

## 未完成・動作制約

**Videoleapとの完全互換ではありません。** WebGL GPUシェーダーの実機動作、VRMの骨格・テクスチャ/材質、正確な音素別リップシンク、長尺での安定性、H.264/AACの確実なMP4書き出し、Nothing Phone実機の操作性、VOICEVOX本体とのライブ通信は未検証・未対応です。生成字幕は台本とWAVの長さからの近似なのでタイミングを必ず校正してください。

**音声と3Dモデルの利用条件**：ずんだもん等の一部VOICEVOX音源は宗教活動への利用を禁止しています。VRMもモデル内の商用・宗教利用条件と、外部の配布条件を確認してください。宗教団体の宣伝に使えると自動判定・保証するものではありません。

PWAのブラウザストレージは容量不足や端末設定で失われる可能性があります。重要な作品は `.subecut` を定期的に端末へ書き出してください。
