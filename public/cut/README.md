# SUBEHA CUT v2.1 — 素材検索の高速化とPixabay公式API

OpenverseとWikimedia Commonsの検索機能を保持しつつ、画像・動画向けのPixabay APIを追加。ユーザーの操作を減らすため、検索結果表示の待ち方とキャッシュを改善した。

## 2026年11月の検索改善

- **キャッシュ**：Pixabay結果は公式API指定の24時間、Openverse/Commonsは10分間ローカルに保持（最大16検索分）。同一語句・素材種別・提供元の再検索は結果を即表示。プライベートブラウズやストレージ制限では保持できない場合あり。
- **前の結果を維持**：次の検索中も現在の一覧を消さず、検索失敗時も前の検索結果を残す。
- **待ち時間の可視化**：検索完了時に結果件数とリクエストの経過時間（ms）を表示。ネットワーク待ちの上限を14秒から9秒へ短縮。新しい検索や画面を閉じる操作で古いリクエストをキャンセル。
- **Pixabay**：画像 `https://pixabay.com/api/`、動画 `https://pixabay.com/api/videos/`。24件ずつ検索し、動画は端末向けの中・小サイズを選択して80MB上限を守る。画像・動画は選択したファイルを端末へダウンロードしてから既存タイムラインに渡す。音楽・効果音検索はPixabay APIの対象外なので既存のOpenverse/Commonsを利用。
- **APIキー**：「無料素材」→「Pixabay API設定」→[Pixabay公式ページ](https://pixabay.com/api/docs/)で取得したキーを入力。「このページで使用」を押す。キーをGitHubのソースや編集データ・localStorageへ保存しない。ページ更新後の入力は再度必要。キーはブラウザからPixabayへのリクエストURLに含まれるので、共有端末やブラウザ拡張のある環境では取扱いに注意。公開向けサービスに拡張する際はサーバー側の秘密情報管理が望ましい。
- **ライセンス**：Pixabayの画像・動画は無条件にCC0ではない。コンテンツ利用条件（https://pixabay.com/service/license-summary/）を表示し、元の作品へのリンクと作者名を残して使用履歴に記録。宗教団体の宣伝等では、人物の肖像権、誤認を誘う支持・推奨表現、商標・権利制限について個別確認する。素材単独の再配布は禁止（単なるサイズ変更やフィルタ適用のみも単独配布とみなされ得る）。
- **運用条件**：Pixabayは標準100回/60秒のレート制限と24時間の結果キャッシュ要件がある。検索結果内の一時的な画像プレビュー表示以外で画像URLを恒久的にホットリンクしない。
- **未検証**：Pixabay実キーによる実ネットワーク通信、公開環境でのCORS、Nothing Phoneでの大容量動画取得・書き出し。これらは端末・ネットワーク・Pixabayのサービス応答に依存する。

## 技術上の改善候補

- 公開ユーザー向けにCloudflare Workersなどの認証済みバックエンドを設け、APIキーをサーバーで管理しつつレート制限と24時間の共有キャッシュを実装。
- 動画素材や巨大音源を編集時に扱う場合は、ダウンロードの進捗・キャッシュ容量管理・OPFS保存・軽量プロキシ生成を別途設計。
- Pixabay以外の素材では、Openverseの匿名APIを保持し、反応しない場合はWikimedia Commonsへ手動で切替可能にする。API利用条件と権利条件を混同しない。

# SUBEHA CUT v2.0 — パブリックドメイン素材・VRM/GLB CG・音声合成

Android Chrome用のローカル動画編集PWA。Videoleap等の他社製品と無関係。旧バージョンの編集プロジェクトを継続できます。

## 新機能

1. **素材を探す**: 画像 / 動画 / 音楽 / 効果音 / 音声 / 3Dモデル / VRM / テクスチャ / HDRI の入口を追加。Wikimedia CommonsでCC0/PD動画・音声を、OpenverseでCC0画像・音声を検索して端末保存・編集へ取り込めます。音楽と効果音は同じ音声検索に用途別キーワードを付け、検索結果の利用条件は個別確認します。
2. **外部サイトの公式リンク**: NASA Images（動画・写真等）、Internet Archive（作品ごとに許諾を確認）、Freesound（CC0を選択）、Poly Haven（CC0のモデル・テクスチャ・HDRI）、VRoid Hub（VRMモデルごとに許諾を確認）へ直接移動。第三者サービスをスクレイピングしません。Pixabay/Pexelsへのリンクも保持。
3. **VRM/GLBの3D CG読み込み**: これまでのOBJに加え、glTF 2.0 GLB形式の基本三角形メッシュを解析して既存CGタイムラインへ配置。静止形状を回転・移動・拡大し、既存Canvas描画/書き出しへ合成できます。VRM1.0の作者・商用利用・政治/宗教利用許諾メタデータを読み、画面に表示します。VRM0.xや通常GLBの利用条件は「不明」と表示します。
4. **音声合成**: 画面下の「声を作る」で、VOICEVOX互換の別起動エンジン（既定`http://127.0.0.1:50021`）に接続。声の種類を取得し、台本・話速・高さ・抑揚を指定してWAV生成・試聴・端末保存・既存の複数音声トラックへ追加。使用話者と必要クレジットを編集データに記録し、一覧テキストとして保存できます。エンジンや音声モデルはこのPWAには組み込まれていません。
5. **ゆっくり音声の取り込み**: AquesTalkの公式ツール等で適切な利用許諾の下に作成したWAVを読み込みます。AquesTalkのエンジンは組み込まず、公式ライセンスページのリンクを表示します。

## 使用方法

- **映像・音楽・効果音**: 「無料素材」→種類を選択→検索。CC0/PD候補を選び、原典・権利を確認→「編集に追加」。動画の直接検索はWikimedia Commons。音声はOpenverse CC0/Wikimedia Commons。商用・宗教団体向けだからといって利用許諾を自動保証しません。
- **3D/VRM**: 「無料素材」→「3Dモデル」または「VRM」→配布元の公式サイトへ移動→モデルの利用許諾を確認して端末に保存。「3D映像」→「＋ 3Dモデルを読み込む」で`.obj`, `.glb`, `.vrm`を選択。VRMモデルを動かせるのは全体の変形のみで、キャラクターの骨格/表情/口パクには未対応。
- **ずんだもん等の音声**: VOICEVOX ENGINEを別の実行環境に起動し、アプリからアクセスできるHTTPS/CORSまたは同じ端末のlocalhost接続先を指定。「声を作る」→「声の一覧を取得」→話者を選ぶ→文章を入力→「声を生成する」→「音声を時間軸に追加」。*先にベース映像/画像を追加してください。*
- **ゆっくり**: 公式AquesTalkPlayerなどからライセンス条件を確認して音声ファイルを保存→「声を作る」→「作成済みの音声を取り込む」。

## ライセンス・権利上の注意（特に宗教団体の広報）

- **ずんだもん、東北ずん子・四国めたん等の音源**: `https://www.zunko.jp/con_ongen_kiyaku.html` の共通規約により、政治活動・宗教活動およびその関連用途は禁止。一般向け商用動画で使える場合でも宗教団体の勧誘・宣伝には使えません。用途を「宗教団体の宣伝」に設定した場合、対象の声の生成をブロックします。VOICEVOX以外の音声ライブラリはそれぞれ別規約です。VOICEVOXによる音声には必要なクレジットを記載してください。イラスト/立ち絵の条件は音源とは別。
- **AquesTalk**: `https://atpw.a-quest.com/howto.html` 。会社・団体・営利利用（広告付き配信を含む）は原則、所定の使用ライセンスが必要です。利用目的による制限も個別確認。
- **VRM 1.0**: `https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/meta.ja.md` 。`allowPoliticalOrReligiousUsage` は初期値 `false`。利用禁止のモデルや商用許諾が不足するモデルは当該用途に使えません。`commercialUsage` も確認してください。VRM0.xや追加許諾は必ず元の配布ページを確認。
- **Poly Haven**: `https://polyhaven.com/license` でCC0素材。公開APIをブラウザから直接呼ぶことはまだ実装していません。API固有のUser-Agent要件とブラウザ制約があるため、公式サイトでのダウンロードへ誘導します。配布ページの表示に従ってください。
- **NASA**: 米国では多くのコンテンツが著作権対象外でも、職員/宇宙飛行士の肖像、NASAロゴ、第三者著作物、広告でのNASAによる推奨を示唆する表現に制約があります。`https://www.nasa.gov/nasa-brand-center/images-and-media/`。
- **Freesound**: CC0以外の音源も多数含まれます。CC BYやNCの素材を無条件に宗教団体の広告へ流用しないでください。パブリックドメイン/CC0表記だけで、肖像権、商標、配布権のすべてが確認済みとは限りません。

## 動作状況・制限

- **実装済み**: CC0/PD動画・音声の検索と取り込み（通信先のCORS等に依存）。モデルダウンロードの公式リンク。GLB/VRMの基本静止メッシュ読込と利用条件表示。VOICEVOX互換HTTP APIへ接続してWAV生成・音声トラック追加、話者クレジット記録。ライセンス制限の注意表示。
- **未実装**: ブラウザ単独でのVOICEVOX/AquesTalk音声合成、VRMのテクスチャ/MToon・ボーン・表情・口パク、3D素材のアプリ内完全検索・自動ダウンロード、全素材のライセンス保証、配布元APIの実運用接続検証。VRM/GLBは48MB以内・三角形45,000以下の非圧縮glTF2.0形式の簡易レンダリングです。
- 音声APIは接続先サーバーのCORS許可が必要。VOICEVOX公式エンジンはlocalhost以外のOriginを既定で拒否します。公開サイトから接続する場合はエンジン側の設定が必要なことがあります。音声生成テストは**模擬API**を使用し、実VOICEVOXエンジンでは未検証です。
- Node自動テスト、スマホ幅のChromiumで模擬API音声生成・WAV取込・VRM権利表示・CC0素材検索を確認しています。Nothing Phone実機でのVRM大容量読み込み、音声合成、長尺書き出し、GPU性能は未検証。
