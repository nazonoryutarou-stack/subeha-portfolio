# SUBEHA CUT Pro v0.7 — manual still-image cutout, clone retouch and editable templates

独立開発のAndroid Chrome向けローカル動画編集PWA。Videoleap/Lightricksとの提携・互換性はなく、商標・UI素材・専用テンプレートは複製していません。

## 新機能

- **背景の透明化**：写真の背景をタップし、色に近い*連続領域*を透明化。許容差と境界ぼかしを変更可能。人物の意味認識AIではありません。
- **クローン修復**：不要部分とコピー元を順にタップし、周辺の画素をソフトブラシで置換する写真修復。AIによる不要物除去ではありません。
- **透明PNGをレイヤー化**：切り抜いた画像をオーバーレイ素材として追加、または現在の静止画クリップのみを新しい画像で置換。元画像は保持。
- **6種類の編集可能なテンプレート**：CINEMA / VLOG / BREAKING NEWS / NOIR / NEON NIGHT / FOUND FOOTAGE。色調・タイトル・映像効果・比率を設定。既存の音声・字幕・映像を削除せず、あとから個別編集できます。
- 生成した画像はIndexedDBへ保存し、既存の`.subecut`素材入りZIPに含められます。
- オフラインキャッシュをv7に更新しました。

## 使い方

1. 動画・写真を追加。「写真修復」を使う場合、編集したい**静止画像クリップ**をタイムラインで選択。
2. 下部ツールバーを横スクロールして**写真修復**を開き、背景消去またはクローン修復を選択。画像上の位置をタップしてから加工します。
3. 背景消去では、加工済みの静止画像で現在のクリップを置換するか、透過画像を新しい映像レイヤーとして追加できます。
4. **テンプレ**で題名を入力してデザインを選択。既存クリップに色とエフェクトを指定、新しいタイトルを追加します。
5. 従来の字幕・音声・書き出し・プロジェクト保存を引き続き利用できます。

## 限界と安全性

- **今回の写真修復は静止画限定。** 人物AI切り抜き、動画内の動く物体の自動削除、高精度なセマンティックマスクではありません。細い髪、複雑な背景、遮蔽には弱いです。修復はコピー元を手動指定します。
- ブラウザメモリを守るため、生成画像は長辺最大**1500px**。元画像は消去しません。
- リアルタイムのMediaRecorder書き出し、コーデック、長尺・4K処理には引き続き制約があります。
- 素材はサーバーに転送しません。ブラウザ内の保存は空き容量・ポリシーの影響を受けます。
- Android実機での操作・書き出しテストは未完了。自動テストとブラウザスモークテストの結果を分けて報告します。
