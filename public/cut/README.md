# SUBEHA CUT v2.4 — GPU立体文字・金属材質・2灯ライティング

Videoleapのユーザー取得資料 `Processors/Schema-Text.json` に存在するPBR特性（metallic / roughness / bumpiness / environmentIntensity / light1 / light2など）を**設計上の参考**に、WebGL 1とCanvas2Dで独立実装した。抽出した独自シェーダー、フォント、素材、プリセット値は使用していない。

## 追加機能と操作方法

1. 動画・画像を読み込む → 「テキスト」で文字を追加 → 対象の文字を選択 → 下部の「立体文字」または文字編集の「立体文字」タブを開く。
2. **材質8種**：クローム、黄金、箔、ビニール、ホログラム、溶岩、陶器、黒曜石。選択するとGPU立体文字が有効になる。各プリセットの数値は独自作成。
3. **表面特性**：金属度、粗さ、凹凸、環境反射、奥行き（0〜36px相当）、縁の丸み、反射の回転速度。材質色も変更できる。
4. **2灯ライティング**：画面内の円形操作盤で☀1と☀2を指で動かす。各ライトの方向、高さ、強度、色を調節できる。
5. **キーフレーム**：前バージョンの「動き」→「現在の時刻に記録」が有効なら金属度・粗さ・奥行き・ライトパラメータなどもキーに保存。プレビューと書き出しで共通の `drawAnimatedTitle` → `drawPbrTitle` 経路を使用。
6. **軽量化とオフライン**：同じ文字のラスター形状を小容量キャッシュしてWebGLのテクスチャ再送を抑える。PWAキャッシュv27で必要なモジュールを含める。WebGLを使えない環境は通常のCanvas2D文字描画へ自動フォールバック。

## 現状の精度と制限

- これは**文字マスクを斜めに押し出して表面をGGX系のマイクロファセット反射で陰影付けする、2.5D表現**。文字の立体ポリゴンを作る完全な3Dメッシュレンダラーではなく、実物の反射・光源の物理シミュレーションでもない。VideoleapのPBRシェーダーと同等の描画ではない。
- 通常のテキストキーフレーム、2Dテロップ、字幕、指編集は維持。PBRモードと**文字・単語・行**単位の個別アニメーションが同時設定されたときは、個別演出を優先して2D描画に戻す。全体単位アニメーションとは併用可能。
- 文字のメインプレビュー内でのドラッグ・ピンチ・回転は従来どおり。材質や光源はタッチスライダー・光源盤を用いる。
- プレビューと書き出しは同じCanvas2D合成結果を使用するが、MediaRecorderの対応コーデックや端末のWebGL品質・長尺安定性は環境に依存する。
- WebGL APIを模した統合試験、非GPUの2Dフォールバック、パラメータの範囲制限、キーフレーム補間を検証した。**Nothing Phone実機のGPUコンパイル・レンダリング・動画書き出しは未検証**。
- サイトを更新したあと、旧PWAが残る場合は再読み込み。作業データは定期的に `.subecut` 形式でバックアップ。

# SUBEHA CUT v2.3 — 可変速度ランプと20種類の場面転換

ユーザーが取得したVideoleapの`Schema-SpeedRamp`、`Schema-SpeedRampControlPoint`、`Schema-Transition`、`Schema-Clip`を参照し、**独自の数式・オリジナルのCanvas2Dエフェクト**として追加した。抽出したJSONや素材・レンダラーをそのままアプリに組み込んだものではない。

## 新しく操作できること

- **速度ランプ**：クリップを選択→「速度」→速度ランプ欄。一定／モンタージュ／ヒーロー／弾丸／ジャンプ／急加速／急減速／旋回／スイング／ドリフト／スプリント／徐々に加速／徐々に減速／クールダウン／ビルドアップの15選択肢。数値曲線は独自設計であり、Videoleapの同名プリセットとの一致は未確認。
- **5つの速度制御点**：0〜100%の区間内の5点の速度を0.25〜4倍の範囲で指で変更。非破壊で保存され、プロジェクトの尺と再生位置を速度の厳密積分から計算。逆再生と途中分割でも時間・曲線を維持。従来の一定速度操作はそのまま利用可能。
- **拡張トランジション**：既存のディゾルブ、フェード、ワイプ、スライド、ズームに加えて上下ワイプ、4方向スライド、円形の開閉、フラッシュ、グリッチ、左右回転を追加。選択画面は日本語表示。全20項目（「なし」を含む）。
- **書き出しへの接続**：プレビューのタイムラインとMediaRecorderの書き出しで同じランプ関数・トランジション関数を使用。Service Worker v26に必要なJavaScriptを追加。

## 実装・品質上の注意

- 加減速は素材のデコード能力とHTMLVideoElementの `playbackRate` に依存する。高速・低速で端末が対応できない場合はシーク補正が入る。動画の音声はブラウザによるピッチ補正やミュート挙動が異なる可能性がある。長尺映像・実機書き出し・音声の正確なピッチ維持は未検証。
- 制御点は元素材の再生方向に沿った**正規化位置**で管理する。この仕様は取得スキーマのtimeValue/timescaleをそのまま再現したものではない。公開する素材は独自のJSON形式で保存され、元アプリとプロジェクトファイル互換にはならない。
- 元スキーマの68種類のトランジションを全て再現したわけではない。今回の拡張は軽量Canvas2D処理であり、元アプリの独自パーティクル、プリズム、光学系シェーダー等はまだ未実装。
- 非線形の時間マッピングと描画ステートについて静的検証・模擬Canvas検証を実施。AndroidのNothing Phone実機の長時間再生・音声・エクスポート実測は未確認。
- 重要な制作データは引き続き `.subecut` の素材入りバックアップとして保存すること。

# SUBEHA CUT v2.2 — 文字・単語・行アニメーションと指編集キーフレーム

Videoleapのユーザー提供テンプレート用JSON Schema（`Schema-Text`、`Schema-AnimationTextName`、`Schema-KeyframeEaseType`）を**設計上の参考**とし、独自のCanvas2D描画モデルを実装。元アプリのスキーマファイル・シェーダー・フォント・画像・アニメーション実装は流用しない。

## v2.2で追加した機能

- **13種のモーションタイプ**：なし／フェード／スライド／拡大／バウンド／タイプライター／波／揺れ／点滅／回転／落下／ぼけ／出現。名前が似たVideoleapの演出と**ピクセル単位で同じ動作という意味ではない**。
- **独立した4単位**：文字・単語・行・全体。日本語の単語分割は対応環境では `Intl.Segmenter` を利用。文字間に時間差を設け、逆順や登場・退場を選択できる。
- **8つの補間選択肢**：線形と、スキーマに登場する7種の数学的イージングに相当する独自曲線。アニメーション時間・文字間の時間差を指で調節。
- **タイトルキーフレーム**：再生位置にキーフレームを記録し、「現在の時刻に記録」を有効にして文字の位置・大きさ・回転・透明度・色・文字間・背景色・影などを変更。キー間は選んだ曲線で補間。既存のドラッグ・ピンチ・回転操作からも位置等を記録可能。キーはプロジェクトJSONへ非破壊保存。
- **共通のレンダラー**：プレビューとMediaRecorderの書き出しを同じ `drawAnimatedTitle()` で処理。古い文字素材の `fade/pop/slide` は従来の見た目を維持。
- **スマホ操作**：下部の「文字アニメ」ボタンまたは「テキスト」→文字選択→「動き」タブから操作可能。

## 操作手順

映像を読み込む→「テキスト」で文字を追加→プレビュー内の文字を選ぶ→「文字アニメ」または「動き」タブ。動きの種類・単位・方向・時間差を選び「この文字を再生」で確認。

位置や大きさを時間変化させるには、再生位置を文字の表示開始後に移動→「＋ 現在位置にキーを追加」→チェックボックスを有効にして、指で文字を動かす。別時刻でもキーを作るとその間を滑らかに補間する。全キー削除で通常の固定文字に戻せる。

## 安全性・制約・検証範囲

- 文字が長い場合、180描画ユニットを超えると端末負荷対策として個別モーションを省略し、通常の文字として描画する。
- キーフレーム時刻は現状ミリ秒精度で記録。Videoleapの内部プロジェクト互換や有理数時間モデル、PBR 3D文字、67種の独自効果、速度ランプ、複合トランジションの完全再現は**未実装**。
- Node形式の回帰テストを `test/text-motion.test.mjs` に追加。Canvasモックの描画、時間補間、保存構造を対象とした内部チェックは通過。実機での指操作・長時間映像・出力の画質は未確認。
- 文字のアニメーションは純粋な2Dレンダラーで、Videoleapの独自エンジンをコピーしたものではない。
- 大事な編集は引き続き `.subecut` としてバックアップすること。

# SUBEHA CUT v2.1 — 台本字幕 / VRM口パク / 指で3D編集

Android Chromeで動作するローカル動画編集PWA。GitHub Pagesから利用可能。Videoleapと同一のソース・素材ではなく、独自実装です。

## v2.1追加

1. **音声から編集可能な字幕を生成**：合成音声の元になった日本語台本を句読点・文字数に基づいて分割。音声クリップの開始時刻と長さへ比例配分し、字幕トラックへ追加する。字幕の時刻は**推定**であり、ASR・音素アラインメントではない。既存の指で字幕を動かす・大きくする・色を変える機能が使える。音声作成画面で字幕を追加するかを選べる。
2. **VRM口パク（限定対応）**：VRM 1.0の表情 `aa`、VRM 0.xの `a` に対応するモーフターゲット形状を読み込み、合成された**PCM16/float32 WAV**の音量変化で口を開閉する。口の形状が埋め込まれていないVRMは動かない。顔を認識したり、正確な音素別口形状やボーン変形を計算する機能ではない。3D編集画面で既存のナレーション音声と手動でも連動できる。モデル素材の利用条件は引き続き確認する。
3. **3Dモデルの指操作**：「3Dを指で動かす」を有効にすると、プレビュー上のドラッグで左右・上下移動、2本指で拡大縮小・左右回転。通常の文字・レイヤー指操作を邪魔しないよう、専用操作中だけ有効にする。移動結果は編集履歴に保存。
4. **3D描画の更新**：GPUが使える場合にはWebGLの頂点シェーダーで口形状を合成。WebGLが使えない場合は従来のCanvas2D代替描画を使用。静的OBJ・口形状のないGLB/VRMは従来通り表示する。Service Workerキャッシュをv21に更新。
5. **既存の保存・編集互換**：以前の`.subecut`を読み込み可能。新しい字幕と音声・VRM間のリンク情報も素材込みアーカイブで保存できる。既存の動画・画像・字幕・重ねがけフィルターなどの編集機能を保持。

## 使い方

- 映像・写真を追加し、下の「3D映像」からVRMを読み込む。「3Dを指で動かす」を選び、モデルをドラッグやピンチで操作する。通常の文字編集に戻る場合は同じボタンで解除する。
- 「声を作る」でVOICEVOX互換エンジンへ接続し、音声を選択して台本からWAVを生成。「台本から字幕も自動作成」を有効にしたまま「音声を時間軸に追加」で字幕も作成。字幕の時間は必要に応じて修正する。
- VRMに `aa` の口形状があれば、音声追加時に連動させるか、3D映像の「口パクと連動する音声」から選ぶ。合成音声は非同期で追加されるため、再生前にWAVを保存・読み込む必要がある場合もある。
- 「保存」で動画素材・モデル・音声・字幕をまとめて`.subecut`へ保存。「書き出す」で完成映像を保存。

## 確認した動作

```sh
cd public/cut
for f in *.mjs integrations/*.mjs; do node --check "$f" || exit 1; done
node --test test/*.test.mjs
python test/smoke-v21.py
python test/smoke-v21-morph.py
```

- Nodeで既存62件＋追加7件＝**69件の自動テスト**。
- Chromium（モバイル420px）で、モックVOICEVOXエンジンのWAV生成→音声追加→字幕生成、CGを指で移動（実タッチ入力を含む）、素材入りアーカイブのZIP内容確認、720×1280程度の短い動画書き出しを検証。ページJavaScriptエラーなし。
- VRMの `aa` モーフを使い、Canvas2D代替レンダラーで口開閉前後のレンダリング画素が変化することを検証。

## 未完成・動作制約

**Videoleapとの完全互換ではありません。** WebGL GPUシェーダーの実機動作、VRMの骨格・テクスチャ/材質、正確な音素別リップシンク、長尺での安定性、H.264/AACの確実なMP4書き出し、Nothing Phone実機の操作性、VOICEVOX本体とのライブ通信は未検証・未対応です。生成字幕は台本とWAVの長さからの近似なのでタイミングを必ず校正してください。

**音声と3Dモデルの利用条件**：ずんだもん等の一部VOICEVOX音源は宗教活動への利用を禁止しています。VRMもモデル内の商用・宗教利用条件と、外部の配布条件を確認してください。宗教団体の宣伝に使えると自動判定・保証するものではありません。

PWAのブラウザストレージは容量不足や端末設定で失われる可能性があります。重要な作品は `.subecut` を定期的に端末へ書き出してください。
