# SUBEHA CUT v1.4 — 指で編集する字幕・テキスト・レイヤーと複数FX

Android Chrome向けのローカル動画編集PWA。Videoleap/Lightricksとは独立したソースコードとブランドで制作しています。

## v1.4 の操作

1. 動画・写真を追加したら「テキスト」でタイトルを追加するか「字幕」でSRT/VTT/Whisper JSONを読み込む。
2. **プレビュー上の文字をタップ**して選択。**指でドラッグ**して移動、**2本指ピンチ**で文字サイズ、**2本指ひねり**で回転。枠右下の↘でサイズ、枠上の⟳で回転も可能。
3. 画面上の小さなメニューで「編集」「色」「複製」「削除」を選ぶ。文字の打ち直し、7色＋任意色、字幕背景の切り替え、文字の登場アニメーションも行える。
4. 字幕は**1つのセリフごと**に位置(x/y)・サイズ・色・角度・背景を保存する。従来の字幕スタイル一括設定も維持。文字ハンドルはHTMLの編集用UIなので書き出し映像に映り込まない。
5. 写真や動画の**オーバーレイ**もプレビュー上で選択して直接移動・拡大・回転。既にキーフレームがある場合、現在の再生時刻のキーを作成または更新する。

## カラー・演出ラボ

- タイムラインからクリップを選び、「フィルタ」「調整」「エフェクト」を開く。従来の数値パネルではなく、タッチ操作の編集シートへ切り替える。
- **ルック4種類**：アナログ映像・夢幻・白黒映画・人工色彩。色と効果を適用したあとも全項目を変更可能。
- **色調5項目**：明るさ、コントラスト、彩度、色温度、白浮き。元の動画を変更せず、Canvasのカラー合成でプレビュー／書き出しに反映。
- **効果10種類**：周辺減光、ピクセル化、色収差、走査線、粒子、光漏れ、柔らかな発光、映画スコープ、2色調、残像。複数重ね、順序変更、削除、開始／終了時刻設定ができる。最大10レイヤー。
- **効果のキーフレーム**：再生ヘッドを動かし、効果の強さを記録する。時間経過で強弱を補間。
- 旧式のフィルター・エフェクト設定も保持し、以前のプロジェクトを壊さないようにしている。

## 動作検証

```sh
cd public/cut
for f in *.mjs integrations/*.mjs; do node --check "$f" || exit 1; done
node --test test/*.test.mjs
python test/smoke-inline.py
python test/smoke-captions.py
python test/smoke-pinch.py
python test/smoke-overlay-fx.py
```

**Node自動テスト38件成功**。追加の純粋関数テスト：2D選択枠、字幕ごとのスタイル、回転・ピンチ計算、動画FXの時間補間、素材込みアーカイブの再読み込み。

Chromiumモバイル相当（420×933px）で、画像の読み込み・テキストドラッグ・2本指ピンチ／回転・字幕ドラッグ・サイズ変更・色変更・画像レイヤードラッグ・プリセット適用・複数エフェクト作成・強度変更・キーフレーム登録を操作検証。JavaScriptのページ例外なし。開発環境の外部ナビゲーション制限のため、ES Modulesを `data:` URLにしたローカル検証で動作確認。

## 現時点の制約

- Android Nothing Phone実機での多指操作、動画書き出し・長尺/高負荷動作は**未検証**。ブラウザのMediaRecorderによる映像出力はH.264/AACを保証しない。
- 複数FX・発光・残像はCanvas 2Dによるリアルタイム合成。性能の低い端末ではフレーム落ちが起こる可能性がある。
- 個別の字幕スタイルはアプリ独自の`.subecut`プロジェクト保存に含むが、SRTへのテキスト書き出しには位置・サイズ等が含まれない（SRT仕様の制約）。
- 3D OBJ・マスク・音声・字幕・既存の編集機能は引き続き利用可能。素材はGitHubにアップロードせず端末内に保存。
