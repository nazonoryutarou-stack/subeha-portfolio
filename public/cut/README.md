# SUBEHA CUT v1.5 — 指でゴミ箱へ削除・日本語で使える編集画面

Videoleapなどのスマホ編集アプリで一般的な操作を参考にした、独立開発のAndroid Chrome向け動画編集PWAです。Lightricks/Videoleapとは無関係であり、他社の専用コード・ロゴ・素材を複製していません。

## 今回の中心: 指でつかんで削除

- **動画・写真、文字、字幕、3D映像**：時間軸で対象を約0.42秒長押しすると、ゴミ箱が表示されます。そのまま指をゴミ箱の上に運んで離すと削除できます。
- **音声、重ねた画像・動画**：時間軸上の素材をドラッグするとゴミ箱が表示されます。ゴミ箱へ持ち込めば削除、それ以外の位置で指を離せば開始時間の移動になります。
- **プレビュー上の文字・字幕・重ねた素材**：今まで通りドラッグで位置を変更できます。画面下側にドラッグして、表示されたゴミ箱で離すと削除できます。
- **誤操作対策**：ゴミ箱の外で指を離しても削除されません。削除直後に「元に戻す」ボタンを表示します。元の素材データは破棄しないため、編集履歴から復元できます。
- **Androidタッチ対策**：長押し中は不要な選択メニューを抑え、ドラッグ中のスクロール処理が操作を中断しないよう修正。従来のタイムラインの左右スクロールと2本指での拡大縮小を保持。
- **詳細設定パネルを邪魔にしない**：画像レイヤーや音声の取り込みが終わったら編集パネルを閉じ、時間軸へ戻ります。

## 日本語表示・操作ガイド

- 画面の「？」を押すと**操作の説明と用語集**が開きます。
- 「オーバーレイ」→「素材を重ねる」、「クロマキー」→「背景色を消す」、「トランジション」→「場面のつなぎ」、「エフェクト」→「映像効果」、「キーフレーム」→「動きの記録点」など、専門語をわかりやすい表示に変更。
- レイヤー位置の `x/y`、`scale`、`opacity`、`rotation` は「左右の位置」「上下の位置」「大きさ」「透明度」「回転角度」へ変更。重なり方の選択肢も日本語に変更。内部データの値や既存プロジェクトは変更しません。
- 数値欄は微調整用で、普段は画面で素材を直接動かしたり拡大・縮小したりできます。

## 主な従来機能

動画・画像・音声の複数トラック、トリム、分割、並べ替え、場面のつなぎ、色の調整・映像効果、文字・字幕（SRT/VTT/Whisper JSON）、背景色を消す、時間ごとの動き、OBJモデルからの3D映像制作、素材入り `.subecut` バックアップ、動画書き出し。

## 再現可能な検証

```bash
cd public/cut
for file in *.mjs integrations/*.mjs; do node --check "$file" || exit 1; done
node --test test/*.test.mjs
python test/smoke-trash.py
python test/smoke-trash-more.py
python test/smoke-touch-device.py
python test/smoke-inline.py
python test/smoke-pinch.py
```

- **42件のNode自動テストに合格**。
- モバイル相当幅420pxのChromiumで、動画・文字・字幕・3D映像・画像レイヤー・音声のゴミ箱削除を試験。動画の削除後のUndo成功。ブラウザ例外ゼロ。
- Chrome DevToolsの**実際のタッチ入力イベント**で、長押し・ゴミ箱へのドラッグ・削除・元に戻すを検証。元はスクロールが操作を取り消す問題があり、`touchmove.preventDefault()`で修正。
- 文字のドラッグ、ピンチ回転、フィルター編集の旧ブラウザ試験も再実行し、成功。

## 限界

- Nothing Phoneの実機でのタッチ操作、長尺編集・発熱・書き出しは未検証。テストはChromiumのモバイルエミュレーションです。
- ブラウザのMediaRecorderが出力するMP4コンテナは、H.264/AAC形式とは限りません。確実な4K・長尺・HEVC書き出しは保証されません。
- 削除はプロジェクト上の参照を取り除く操作で、ストレージ上の元ファイルを永久消去する操作ではありません。復元に必要なデータは保持します。
- 一部の映像用語は従来のプロジェクトとの互換性のため内部の変数名に残っていますが、画面の操作名称・説明を優先して日本語化しています。
