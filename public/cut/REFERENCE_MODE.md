# 編集画面 v2.7 — 取得済みVideoleap監査データを基準としたリファレンスUI

## 参照した資料
- ユーザー提供 `VideoleapAudit.tar.gz`: Videoleap Android 1.40.1の `timeline.png`、`effects.png`、`effects.xml`（Android 16、1260×2800）。
- `VideoleapDeepAudit-SUMMARY.tar.gz`: UI起動時の画像とXML、APKエントリの索引。
- `VideoleapDeepAudit-SCHEMAS.tar.gz`: Draft-7スキーマ78個、フィルター・アニメ・トランジション等の分類。含まれるテンプレート例はappVersion 1.19.2であり、実機アプリ版1.40.1と異なる。
- ユーザー提供画像・端末個人情報・メーカーのロゴ画像はGitHubに公開しない。

## 今回実装したこと
- 画面ヘッダ、中央プレビュー、再生、固定赤色再生ヘッド、サムネイルタイムライン、右端赤色＋、Undo/Redo、下部ツール列を実機スクリーンショットに近い配置へ変更。
- 下部の主要カテゴリを、実機で確認した順序「マジック編集 / オーバーレイ / テキスト / オーディオ / フィルタ / 調整 / エフェクト」を基本に変更。キャンバス、字幕、すべては横スクロール後方。
- エフェクト画面を横スクロール式に変更し、実機で確認できたシェイク、プリズム、オフセット、古い映画、モザイク、焦点ぼけ、RGB、パターン、スキャン、カレイドを先頭に配置。
- 従来の独自CGスタジオ、エンジン統合機能、AI音声ラボ、画像修復スタジオをUI初期化経路・通常メニュー・オフライン配布対象から外した。
- ブランド文字、世界観コピー、専用ラボのメニューと独自Lookプリセットの入口を削除。汎用の「動画編集」名と独自の中立アイコンを使い、Videoleap公式アプリを偽装しない。
- 既存のタイムライン、テキスト指操作、回転0°復帰、オーバーレイ別行表示、素材管理・音声・字幕・書き出しコードは残した。プロジェクト内データを破棄しない。
- オリジナルCGシーンはタイムライン・レイヤー一覧に表示しないが、古い編集プロジェクトの記録は消さない。表示・出力のサポートはこのモードでは対象外。
- PWAキャッシュをv30へ更新し、不要な独自スタジオ・古いブランドアイコンのキャッシュ対象を削除。

## 証拠不足と非同等箇所
**完コピ達成の主張ではない。** 入手済みの情報からUI配置と機能分類を寄せた段階。
- iPhone版Videoleapのアプリ内UI、実行コード、UIリソースは未取得。Android版のスクリーンショットからiPhone版を厳密再現することは不可能。
- スキーマに列挙されたフィルター108名、フォント130識別子、文字アニメ67名、トランジション68名は、個々の処理アルゴリズムやUI座標を示さない。
- エフェクトシェーダー、マジック編集、AI処理、出力品質、タッチ慣性・ベジェ曲線、各画面のピクセル一致は未検証。
- 既存実装で動く効果とVideoleapの同名効果が同じ映像を出すとは限らない。
- コードの静的検査と構文確認は実施したが、Nothing Phone・iPhoneの実機UIと書き出しの回帰テストは未実施。

## 操作
1. 編集サイトを開いて動画か画像を取り込む。
2. 下部の「オーバーレイ」「テキスト」「オーディオ」「フィルタ」「調整」「エフェクト」を選択。
3. 重ねた素材はタイムラインで別行表示。Undo/Redo付近の「レイヤー」から一覧表示と順序・可視性編集。
4. 画面上のテキストを選択するとドラッグ・回転が可能。「⟲ 0°」で水平へ戻す。
5. 必要なら「すべて」から保存・読み込み・追加編集に進む。

一般公開のGitHub Pagesアプリなので、先に編集プロジェクトを保存してから更新を試すこと。旧版が残るときは再読込する。
