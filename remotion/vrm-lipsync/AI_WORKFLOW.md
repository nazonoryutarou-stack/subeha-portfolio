# AI切り抜き運用

## 目標

音声と文字起こしをAIに渡したら、AIは**面白い発言を選ぶことだけに集中**する。
秒数合わせはローカル側がWhisperで行う。

最終的には:

1. AIが文字起こしから「切るべき発言」を選ぶ
2. `jobs/current.json` に `quote` / `anchor` / タイトル等を書く
3. `npm run clip`
4. Whisperが元音声をタイムコード化
5. `anchor` を音声認識結果から探して開始・終了位置を自動決定
6. 前後の文脈を足して音声を切る
7. 字幕・口パク・見出し込みでMP4を書き出す

## AIが選ぶ基準

候補区間は原則 15〜60秒。長くても90秒程度。

優先順位:

1. **一文で引っ掛かる** — 冒頭3秒以内に続きを聞きたくなる言葉がある。
2. **本人にしか言えない** — 一般論ではなく、独自理論・変な比喩・強い断言・現場感がある。
3. **単独で成立する** — 前後5分を知らなくても意味が通る。
4. **展開がある** — 問い→説明→オチ、否定→例え→結論など、小さい物語になっている。
5. **引用したくなる** — タイトルにできる一文が含まれる。
6. **既存切り抜きと被らない** — 同じ主張の反復より新しい角度を優先する。

減点:

- 固有の相談者情報が必要
- 前置きだけで終わる
- 内輪文脈が強すぎる
- 単なる相槌や長い沈黙が多い
- 医療・法律・危険行為など、短尺化で誤解が大きくなる部分
- 切ることで本人の意味が反転する部分

## AIが返すjob

推奨形:

```json
{
  "sourceAudio": "inputs/source.m4a",
  "sourceLabel": "Gravity 第157回",
  "quote": "牡蠣食えば、謎は深まるばかりやな",
  "anchor": "謎は深まるばかりやな",
  "contextBeforeMs": 1800,
  "contextAfterMs": 2600,
  "title": "観測したら、分かるとは限らない",
  "hook": "答えが増えるどころか、謎が増えることもある。",
  "telop": ""
}
```

### quote

AIが「この発言を核に切り抜く」と判断した本文。文字起こしから勝手に言い換えず、原文を優先する。

### anchor

Whisper結果から検索するための短い特徴句。
`quote` 全体より、言い間違いや認識差が出にくい6〜20文字程度の特徴的な部分がよい。

### contextBeforeMs / contextAfterMs

核となる発言の前後に何ミリ秒残すか。
前に問いや振りがある場合は `contextBeforeMs` を長くする。
オチの余韻や補足が必要なら `contextAfterMs` を長くする。

### startMs / endMs

どうしても時刻を固定したい場合だけ指定する。
指定されていれば quote検索より優先する。

## ローカル側の処理

`npm run clip` を実行すると、タイムコード付き文字起こしが無ければ自動的に `npm run transcribe` 相当を実行する。

Whisperの結果は `inputs/source.captions.json` にキャッシュする。同じ音声ファイルなら次回以降は再利用する。
音声が変わればファイルサイズと更新時刻を見て再生成する。

`quote` / `anchor` が見つからない場合は**適当な時刻を推測せず停止する**。

## 実行

```bash
cd remotion/vrm-lipsync
cp jobs/current.example.json jobs/current.json
# inputs/ に元音声を置き、jobをAI生成内容へ置換
npm run clip
```

初回だけWhisper.cppとモデルの準備が入るので重い。以後はキャッシュされる。

出力: `out/kiritori.mp4`

## 理想のチャット運用

ユーザー:

> この音声と文字起こしから切り抜き作って

AI:

1. 文字起こし全体を読む
2. 候補を内部で比較し、最も強い一本を選ぶ
3. `quote` と `anchor` を原文から抜く
4. タイトル・フック・前後余白を決める
5. `jobs/current.json` を生成
6. レンダリング可能な環境なら `npm run clip` まで実行
7. 完成MP4を返す

ユーザーは秒数を指定しない。

## 原則

**面白さはAIが決める。時刻は音声から機械的に決める。**

これを逆にしない。AIが存在しない秒数を捏造したり、Whisperが「どこが面白いか」を決めたりしない。
