# AI切り抜き運用

## 目標

音声と文字起こしをAIに渡したら、AIが面白い箇所を選び、`jobs/current.json` を作る。
その後はローカルで `npm run clip` を実行するだけで縦動画を書き出す。

## AIが選ぶ基準

候補区間は原則 15〜60秒。長くても90秒程度。

優先順位:

1. **一文で引っ掛かる** — 冒頭3秒以内に続きを聞きたくなる言葉がある。
2. **本人にしか言えない** — 一般論ではなく、独自理論・変な比喩・強い断言・現場感がある。
3. **単独で成立する** — 前後5分を知らなくても意味が通る。
4. **展開がある** — 問い→説明→オチ、否定→例え→結論など、小さい物語になっている。
5. **引用したくなる** — タイトルにできる一文が含まれる。
6. **既存切り抜きと被らない** — 同じ主張の反復より新しい角度を優先する。

減点:

- 固有の相談者情報が必要
- 前置きだけで終わる
- 内輪文脈が強すぎる
- 単なる相槌や長い沈黙が多い
- 医療・法律・危険行為など、短尺化で誤解が大きくなる部分
- 切ることで本人の意味が反転する部分

## AIが返すもの

`jobs/current.json` は以下の形にする。

```json
{
  "sourceAudio": "inputs/source.m4a",
  "sourceLabel": "Gravity 第157回",
  "startMs": 125000,
  "endMs": 158000,
  "title": "牡蠣食えば、謎は深まるばかりやな",
  "hook": "観測したら、分かるとは限らない。",
  "telop": "",
  "captions": [
    {
      "text": "字幕本文",
      "startMs": 131200,
      "endMs": 134800,
      "timestampMs": 131200,
      "confidence": null
    }
  ]
}
```

`captions` の時刻は元音声基準の絶対時刻。`npm run prepare` が切り抜き開始時刻を引いて動画内時刻へ変換する。

## 実行

```bash
cd remotion/vrm-lipsync
cp jobs/current.example.json jobs/current.json
# sourceAudio / 時刻 / 文言 / captions をAI生成内容へ置換
npm run clip
```

出力: `out/kiritori.mp4`

## 理想のチャット運用

ユーザー:

> この音声と文字起こしから切り抜き作って

AI:

1. 文字起こし全体から候補を複数抽出
2. 音声と照合して開始・終了位置を決定
3. 最も強い1本を選ぶ
4. タイトル・フック・字幕を作る
5. `jobs/current.json` を生成
6. レンダリング可能な環境なら `npm run clip` まで実行
7. 完成MP4を返す

## 注意

文字起こしに時刻情報がない場合、AIが音声を直接参照できる環境なら音声から時刻を決める。
音声を解析できない環境では、タイムコード付き文字起こしまたは音声認識工程が別途必要。推測だけで時刻を作らない。
