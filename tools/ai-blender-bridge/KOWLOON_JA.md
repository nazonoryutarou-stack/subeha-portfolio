# 九龍城砦をBlenderで自動実行する

現在の命令は無彩色OBJ v0.15の西南角です。昼夜の原写真で共通に見える上層帯材3段の表面を追加しました。157部材・902面を作成します。元の4組の折返しの頂点と面を保持し、隠れた裏面や厚みは追加していません。

## 接続済みの端末で受け取る

Termuxのサーバーが動いていてBlenderのアドオンが有効なら、新しい命令を通常1〜2分で取り込みます。接続を再開したいときは、既存の自動接続アドオンを一度オフ→オンにします。現在の命令は既存のJSON操作だけを使い、エージェントの追加更新を必要としません。

ジョブIDは `kwc-v15-gallery-20261128-a1` です。同じIDを二重に実行しない仕組みを維持しています。

1. 現在のBlenderプロジェクトを `before-kowloon` のラベルで端末内へ保存する。
2. 専用シーン `AI Bridge Studio` を作り直し、157部材を配置する。他のシーンは保持する。
3. 完成した作業状態を `completed-kowloon` のラベルで保存する。
4. 640×426のPNGを出力する。モデル保存を先に行うため、画像出力で失敗してもモデルの保存が残る。

保存先は `~/.ai_blender_bridge/outputs/`。切替前の保存に失敗した場合は、それ以降の作り直しを実行しません。元の専用シーンへの手作業の修正は、保存したプロジェクトに残ります。自動的に新しい基準模型へ合成する処理はありません。

端末の `Last result` でこのIDと `ok` を確認できます。GitHubへの登録だけでスマートフォンの実行成功とは判断しません。こちらへ端末の状態や画面を常時送信する仕組みは追加していません。

各部材の出典、判読状態、仮定を命令内へ保持しています。OBJのY上向きからBlenderのZ上向きへ回転し、表示原点を記録しています。モデルには塗装・テクスチャを付けません。照明と灰色の背景は表示確認用です。

## 復元の確かさ

今回の追加面は、以前に復元した帯材の三角面を延長する作業上の制約を使い、昼夜それぞれで採録した材料の輪郭の共通範囲へ限定しました。衣類などで隠れた区間と、両写真が合わない区間は空けています。

調べた4段のうち、別の写真の輪郭とのずれが約4.86画素だった1段は追加を保留しました。採用した3段の最大の差は約1.05、1.88、2.32画素です。これらは画像上の照合値で、実寸精度ではありません。面の延長、旧カメラの校正、絶対寸法、地図への配置には不確かさがあります。未観察の室内・裏面・床厚は作っていません。

自由な奥行きを持たせる計算では、読取りを1.5画素動かすと端点が大きく変化したため、その奥行き案は採用していません。

全域の高さ不明215区画は平面表示、北部19棟の階高と通路高は作業値です。v0.14の全域への配置試案も、確定した位置として統合していません。

## 再生成

同じ版の `model/` と `evidence/project_manifest.json` を使います。

```sh
python kowloon_job.py /path/to/Kowloon_Uncoloured_OBJ_v15 \
  --view gallery --id kwc-gallery-next-001 \
  --save-before --save-after --render --out jobs/current.json
```

`--view gallery` が今回の追加版、`facade` が従来版です。`no24`、`city`、`roofs` も保持しています。`--save-after` は模型完成後・任意の画像出力前に保存します。

[デスクトップでの検査結果](jobs/kowloon/desktop_validation_v15.json)には、実際のHTTP受信・作成・保存・画像出力・二重実行防止・元シーンの保持を収録しています。デスクトップBlender 4.3.2で同じ命令を検査しました。今回のv0.15について、スマートフォンでの実行結果は未受信です。
