## 運用規則

- チャット添付や端末内ZIPだけを正本にしない。
- 完成版は必ずこのディレクトリへ保存する。
- GitHub Pagesへ公開するファイルとGitHub上のファイルを同一にする。
- 外部URL、API、購入リンクは各作品READMEへ記録する。
- 大幅改修の前にバックアップを作成する。
