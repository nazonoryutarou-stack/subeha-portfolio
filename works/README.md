## 運用規則

- チャット添付や端末内ZIPだけを正本にしない。
- 完成版は必ずこのディレクトリへ保存する。
- Neocitiesへ上げるファイルとGitHub上のファイルを同一にする。
- 外部URL、API、購入リンクは各作品READMEへ記録する。
- 大幅改修はブランチとPRで履歴を残す。
- 完成扱いにする前に、GitHub上の実ファイルを再取得して存在確認する。
