# パない神「バリ・レベチ」様

願いを聞くと「もう始めてる」と返答する架空神格の公式祈願端末。

## ファイル

- `index.html`：入口とメタ情報
- `content.js`：画面本文
- `style.css`：ネオン神格UI、レスポンシブ、モーション停止
- `app.js`：神体円環、願いID、神託、進捗ログ、電子音
- `ogp.svg`：共有用画像

本拠地からの想定URL：`/works/bari-rebechi/`

入力内容は外部送信されず、同一タブの `sessionStorage` に一時保存される。医療、法律、金銭、安全等の現実的判断や成果を保証するページではない。
