# カモノハシ式神四十体・大阪横浜海上輸送作戦

霊務技術報告 第001号。全高約2メートルのカモノハシ型式神40体を大阪から横浜へ海路移送し、個人防衛へ配備したという作戦記録を、海上輸送管制室として実装した特設ページ。

## ファイル

- `index.html`：構造・埋め込み式の個体台帳フォールバック
- `style.css`：画面、印刷、モーション停止、レスポンシブ
- `app.js`：作戦再生、海況API、40体台帳、隊列、配置、文書、仮仕様生成
- `ogp.svg`：共有画像

## API

Open-Meteo Marine APIから、選択した海域の波高・周期・海面温度・海流を取得する。接続失敗時は内蔵値へ退避する。表示値は作戦演出・参考用で、航海判断には使用しない。

## Neocities

`works/kamonohashi-operation/` の内容を同じ階層へアップロードする。想定URL：

`https://あなたのID.neocities.org/works/kamonohashi-operation/`

## 購入導線

現時点ではココナラ電話相談へ接続。個別式神設計の専用商品ができたら `index.html` と `app.js` 内のURLを置換する。

## 安全表示

霊視・創作・祭祀実践上の記録であり、物理的な安全、防犯、医療、法律、警察等を代替しない旨をページ内に明示。
