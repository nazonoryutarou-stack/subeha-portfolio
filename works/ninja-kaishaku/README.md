# 忍者解釈

## ファイル

- `index.html`：入口とメタ情報
- `pack-1.js`〜`pack-5.js`：導入、全32事件、結末
- `style.css`：事件記録UI、スマホ表示、演出停止
- `app.js`：死亡者カウンター、読書進捗、文字サイズ変更
