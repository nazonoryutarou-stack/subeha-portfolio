# 忍者解釈｜忍者災害対策端末

短編小説「忍者解釈」を、なます市警の忍者災害対策端末として再構成した特設ページ。

## 現在の構成

- `index.html`：公開入口。事件本文パックと端末スクリプトを読み込む
- `pack-1.js`〜`pack-5.js`：導入、全32事件、結末
- `style.css`：分割CSSの読込口
- `style-1.css`〜`style-3.css`：基盤、事件UI、レスポンシブ
- `app-1.js`：端末起動、画面再構成、背景演出
- `app-2.js`：事件分類、検索、座席表、鑑識パネル、進捗
- `app-3.js`：表示設定、音、関係図、キーボード操作
- `ogp.svg`：SNS共有画像

## 主な機能

- 起動シークエンス
- 32名の座席表と事件ジャンプ
- 氏名・死因・本文検索と分類フィルター
- 現在の事件を表示する鑑識パネル
- 読書進捗、死亡者数、忍者汚染率
- 事件間の警報ログ
- 天井裏の巣へ収束する関係図
- 文字サイズ、一覧表示、演出停止、任意効果音
- 印刷用レイアウト、スマートフォン対応

## Neocities

Neocities向け配布版は `index.html` にCSSとJavaScriptを埋め込んだ一枚HTMLとして別途生成する。公開時には一枚版の `index.html` と `ogp.svg` をアップロードする。
